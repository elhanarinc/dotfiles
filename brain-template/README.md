# Living Brain

This is a local, data-free knowledge base shared by terminal agents. Register a project with:

```bash
node "$HOME/Obsidian/brain/bin/register-project.mjs" /path/to/project
```

The scripts print relevant context at session start, append concise durable notes at session end, and regenerate a Markdown index. Keep secrets, credentials, raw transcripts, and employer data out of this vault.
