# Living Brain Contract

At the beginning of non-trivial repository work, read the context printed by the living-brain session hook. Before ending, capture durable decisions, current state, blockers, and next steps. Never store credentials, authentication material, raw chat transcripts, or generated caches in the brain.

If the current repository is not registered, run:

```bash
node "$HOME/Obsidian/brain/bin/register-project.mjs" "$PWD"
```
